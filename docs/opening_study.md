# 序盤研究ドリル（`analyze_opening_study.py`）

序盤（既定は 1〜50 手目）に **何度も出てきた同じ局面** のうち、疑問手以上を指したことがある局面を探し、復習用のレポートにします。

- 入力は悪手検出（[mistake_analysis.md](mistake_analysis.md)）の結果と棋譜だけです。エンジンは使わず、数秒で終わります
- 新しい対局を `analyze_mistakes.py` で解析したあとに実行し直すと、レポートが更新されます

```bash
.venv/bin/python analyze_opening_study.py
```

## 出力

| ファイル | 内容 |
|---|---|
| `data/analysis/study/opening_study_report.md` | 勉強用レポート。サマリー・早見表・局面別の詳細カード・別枠（単発の大悪手） |
| `data/analysis/study/opening_positions.csv` | 局面ごとの集計（1 行 = 1 局面）。フラッシュカードや Web UI 用 |

## 集計の方法

1. `analysis_index.csv` と `games_summary.csv` から、指定した評価関数（既定: 最後に解析した対局のモデル）・手合い（既定: 平手）の対局を選ぶ
2. 各対局の CSA を再生して、自分の手番の着手前 SFEN を作り、`moves/{game_id}.csv` の行と結び付ける
3. `mistakes.csv` を `game_id` + `ply` で結び付け、第2パスの値（カテゴリ・低下幅・候補手・反撃手順）を使う。第2パスが無い手は第1パスの値を使う
4. SFEN から末尾の手数を除いた **盤面 + 手番 + 持ち駒** で同じ局面をまとめる（手順前後で合流した局面も 1 つ）

各手の判定は次のとおりです。

| 判定 | 条件 |
|---|---|
| 詰み逃し / 大悪手 / 悪手 / 疑問手 | 悪手検出のカテゴリ（第2パスで確定したもの） |
| 最善一致 | 実戦手が第1パスの最善手と同じ |
| 問題なし | 上のどれでもない（最善手ではないが、低下が疑問手の基準未満） |

## 抽出条件とパターン

次をすべて満たす局面を「問題局面」とします。

- その局面が最初に出てきた手数が `--max-ply`（50）以下
- 遭遇回数 `--min-encounters`（2）回以上、疑問手以上 `--min-mistakes`（1）回以上
- 着手前の期待勝率の平均が `--decided-low`（15%）〜 `--decided-high`（85%）。大勢が決まった局面は定跡研究の対象外にする

| パターン | 条件 | 復習のしかた |
|---|---|---|
| 固定化した悪手 | 疑問手以上率 ≥ `--habit-rate`（60%）で、いちばん多く指した手が疑問手以上 | 誤って覚えた手・手癖を AI 推奨手で上書きする |
| 分岐の迷い | それ以外（正しく指せた回もある、または指し手が割れている） | 正解した回と間違えた回を比べ、反撃手順で悪い理由を理解する |
| 単発の大悪手（別枠） | 1 回しか出てきていないが、勝率が `--single-blunder-drop`（config の大悪手基準 20pt）以上下がった | 既定は一覧表のみ。`--single-blunder-cards` で詳細カードも出す |

並び順は既定で **累計勝率損失**（その局面で失った期待勝率の合計。正解した回の小さなマイナスは 0 として扱う）の大きい順です。`--sort mistake_rate | encounters | ply` で変えられます。

### 注意

- 同じ手でも、対局ごとの解析の揺れ（マルチスレッド探索・第1パスの短い思考時間）で「問題なし」と「疑問手」に分かれることがあります。その場合は「分岐の迷い」に入ります
- AI 推奨手は、その局面で第2パスを行った対局のうち最も新しいものの結果です

## オプション

| オプション | 既定値 | 意味 |
|---|---|---|
| `--max-ply` | 50 | 対象にする手数の上限 |
| `--min-encounters` | 2 | 遭遇回数の下限 |
| `--min-mistakes` | 1 | 疑問手以上の回数の下限 |
| `--model` | 最後に解析したモデル | 評価関数の ID |
| `--handicap` | 平手 | 手合い |
| `--mode` | すべて | 持ち時間（`shogi5` など。複数指定可） |
| `--decided-low` / `--decided-high` | 0.15 / 0.85 | 大勢判明として除外する期待勝率 |
| `--habit-rate` | 0.6 | 「固定化した悪手」とする疑問手以上率 |
| `--single-blunder-drop` | 0.20 | 別枠の勝率低下の下限 |
| `--single-blunder-cards` | なし | 別枠も詳細カードで出す |
| `--sort` | total_drop | 並べ替え |
| `--top` | 10 | 早見表の件数 |
| `--out-dir` | `data/analysis/study` | 出力先 |

## `opening_positions.csv` の主なカラム

| カラム | 内容 |
|---|---|
| `rank` / `pattern_type` | パターン内での順位 / パターン |
| `normalized_sfen` / `sfen_before` | 名寄せキー（手数なし） / 代表の SFEN（最も早い手数で出てきた回） |
| `side` / `min_ply` / `avg_ply` | 手番 / 最小・平均手数 |
| `total_encounters` / `mistake_count` / `mistake_rate` | 遭遇回数 / 疑問手以上の回数 / その割合 |
| `n_mate_miss` / `n_blunder` / `n_mistake` / `n_dubious` | カテゴリ別の回数 |
| `total_winrate_drop` / `avg_mistake_drop` / `avg_winrate_before` | 累計勝率損失 / 間違えた回の平均低下 / 着手前の平均期待勝率 |
| `top_move_*` / `worst_move_*` | 最も多く指した手 / 最も多く間違えた手 |
| `cand1_*` 〜 `cand3_*` | AI 推奨手（第2パス MultiPV） |
| `played_moves` | 指した手ごとの回数と判定の内訳（`▲２八飛(24)×2[悪手2]` の形式, ` ; ` 区切り） |
| `game_ids` | 該当対局（空白区切り） |
